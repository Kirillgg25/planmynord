О проекте PlanMyNord

PlanMyNord помогает собрать поездку по Норвегии в одном месте

Это учебный и практический проект для планирования маршрутов: даты, бюджет, остановки, аэропорты, погода, карта и идеи по городам собраны в один понятный сценарий.

Сейчас используется Рабочая версия сайта

Функции постепенно дорабатываются: часть данных считается внутри сайта, часть открывает внешние сервисы для проверки.

Планирование

Что уже делает сайт

  • Создаёт маршрут по датам, бюджету, людям и выбранным остановкам.
  • Показывает примерный бюджет: жильё, еда, машина и запас расходов.
  • Даёт сезонные советы по одежде и темпу поездки.
  • Показывает идеи по городам: места, еда, районы, погода и мини-карта.
Карты

Карты и маршруты

Для интерактивной карты используется Mapbox GL, а слой `map-engine.js` уже подготовлен так, чтобы позже можно было переключаться на MapLibre.

Билеты

Аэропорты и перелёты

Страница билетов не продаёт билеты напрямую. Она готовит поиск по аэропортам и открывает Google Flights, Kiwi и Skyscanner.

Погода

Погода и сезоны

Для городских страниц используется прогноз погоды, а планировщик дополнительно определяет сезон по датам поездки.

Профиль

Аккаунт и сохранение

Профиль нужен для сохранённых маршрутов и публикации готовых идей. Основные функции планирования остаются открытыми.

Что используем

Текущие технологии и внешние сервисы

HTML CSS JavaScript Node.js Express SQLite / PostgreSQL Mapbox Open-Meteo Google OAuth Stripe / Vipps Google Flights Kiwi / Skyscanner

Маршруты, цены и погода являются подсказками для планирования. Перед поездкой нужно проверять билеты, дороги, часы работы и правила у официальных сервисов.
